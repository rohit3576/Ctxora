These numbers are **not the baseline** — hash embeddings approximate lexical
search. They smoke-verify the harness and already expose the expected failure
shape:

- `followup` R@5 = 0.00 — bare follow-ups retrieve nothing (R2's target).
- `table` R@5 = 0.33 — spec-table lookups retrieve the wrong section (R4's target).
- `identifier` R@5 = 0.90 here only because hash embeddings are lexical; real
  dense embeddings are expected to drop this materially (R3's target and the
  exact number the live baseline will measure).
